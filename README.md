# ✈️ Global Aviation Performance & Safety Analytics (Power BI)

## 📌 Project Overview
This interactive Power BI dashboard provides an executive overview of global airline operations, flight safety, passenger trends, and financial recovery. It is designed to help aviation analysts and decision-makers monitor revenue metrics and safety records in real time.

---

## 📊 Key Insights & Features
- **Executive KPIs:** Real-time tracking of Total Passengers (369.10M), Average Load Factor (83.99%), Total Revenue ($6.68B), Total Incidents, and Fleet Size.
- **Incident Analysis:** Categorized analysis of incidents by severity (fatal crash, ground incident, collision).
- **Revenue Breakdown:** Comparative revenue insights by business model (Legacy, Low Cost, Regional), year, and airline.
- **Route & Region Metrics:** Interactive volume analysis across key aviation routes and global regions.

---

## 🛠️ Tools & Technologies Used
- **Business Intelligence:** Microsoft Power BI Desktop
- **Data Modeling:** Power Query, DAX (Data Analysis Expressions)
- **Data Visualization:** Custom KPI Cards, Slicers, Line Charts, Donut Charts, and Custom Dark Theme UI
